# Optimus Estética

Sistema minimalista para studio de estética: login, cadastro de clientes com aniversário, agenda com check de serviço feito, cadastro de serviços e avisos com mensagens prontas no WhatsApp (parabéns, confirmação de agendamento e acompanhamento pós-serviço).

## Como usar
Abra o `index.html` no navegador ou publique em qualquer hospedagem estática (Vercel, GitHub Pages, Netlify). No primeiro acesso, crie seu usuário e senha.

## Importante
- Os dados ficam salvos no navegador (localStorage) do aparelho em uso; não sincronizam entre aparelhos.
- O login protege apenas o acesso local e não substitui uma autenticação com servidor.
